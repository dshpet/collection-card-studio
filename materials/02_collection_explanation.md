# **Описание коллекций**

**Коллекция -** это набор из тематических карточек, которые игрок собирает в разных игровых активностях. Коллекция состоит из 16 наборов, в каждом из которых по 10 карт. 

**Каждая коллекция** посвящена одной широкой теме например «Кино», «Путешествие», «Лето» и т.п.

**Наборы (сеты)** - это подтемы коллекции. Они должны быть разнообразными и не повторяться. Например, для “Летней Коллекции”- это “Пляж”,“Сад”, “Спорт” и т.п.

**Карточки** подбираются под тему набора (сета). Например, для набора “Пляж” - это надувной пляжный мячик, замок из песка, пляжная сумка и другое. 

Карточки с предметами имеют разную **редкость**. Редкость не влияет на визуальное отображение предмета. 

Также есть **золотые карточки** - наиболее ценные карты с изображениями ключевых персонажей коллекции. Персонажи на карточках отыгрывают ироничную эмоциональную ситуацию. На одной золотой карточке, не больше 2 персонажей.   
   
16 сет - это гранд “сет”. Он содержит только золотые карточки, а тема сета является кульминационной в наборе. Например “Летняя вечеринка”
